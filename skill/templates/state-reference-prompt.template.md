# State Reference Prompt Template

Use this after the user approves the state action plan. Generate or edit one clean state reference image at a time.

```text
Create a clean state reference image for a Codex desktop pet.

Pet identity:
- Pet name: …
- Pet type or subject: …
- Personality or overall feeling: …
- Visual style or material: …
- Primary palette: …
- Must preserve: …
- Forbidden additions or changes: …
- Directional asymmetry: …

State:
- Codex state: …
- Action: …
- Mood: …

Composition:
- Complete pet form visible; do not assume humanoid anatomy.
- Keep the chosen style readable at 192x208.
- Keep the pet centered with generous empty margin around its silhouette, attached features, and props.
- Avoid cropping, detached effects, text, labels, extra UI, scenery, or unrelated props.
- If a prop is required, keep it compact and visually connected to the state action.

Output:
- One clean reference image.
- Flat simple background is acceptable.
- Do not make a sprite strip yet.
```
